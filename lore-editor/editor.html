Data Flow Reference

Threads (threads.json): Categories of knowledge (e.g. PEN, CIPHER).

Variables (parameters.json -> VARS): Dynamic engine state holding the truth (e.g. PEN: 42).

Lock Threads (puzzles.json -> LOCK_THREADS): Connects a Thread to a Variable. If a puzzle requires the CIPHER thread, it maps CIPHER to the CIPHER VAR.

Clues (clues.json): Assigned to a thread. If the active puzzle's LOCK_THREADS doesn't include the clue's thread, the clue is skipped!

Reachability: Every thread a puzzle locks against must actually be delivered by at least one lore.json/clues.json/foreshadow.json entry, or that objective can never be completed by a player.

Templates: Every ${...} token in every text field is actually evaluated against a live mock context, the same way the engine evaluates it at runtime, to catch malformed expressions, unknown variables, and missing $ typos before they ship.
