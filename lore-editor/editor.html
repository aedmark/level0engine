Editor Guidelines

  • ⚙️ System Parameters: Define variables, names, and global game logic. System variables can be injected into text fields using ${var} syntax.
  • 🔐 Lock Mechanics: Entries in clues.json MUST use the CIPHER or TELL threads, and link directly to locks defined in puzzles.json.
  • 🎬 Exit Conditions: foreshadow.json and finales.json are tightly coupled. Foreshadowing texts provide location-specific hints that ultimately lead players to the corresponding finale options.
  • 🌍 World Building: Entries in lore.json add general world flavor and CANNOT use the CIPHER or TELL threads to prevent confusing players.
